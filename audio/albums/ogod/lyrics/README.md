# Preserved, unverified LRC examples

The `.lrc` files in this directory predate the source-catalogue repair. Their text and timings have not been verified against the artist's recordings or approved lyric sources. They must not be presented as recovered OGOD lyrics.

The files are preserved for provenance and any useful implementation examples. The active catalogue sets `hasLyrics: false` and exposes no `lyricsUrl`, so playback does not load these examples. Replace or promote a file only after verifying its text, attribution, track identity and timestamps against a real source.

See [the source catalogue record](../../../../docs/SOURCE_CATALOGUE.md).
